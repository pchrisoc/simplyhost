# Debian

## What is Debian?
- [Debian](https://www.debian.org/) is a free to use open-source operating system built on the [Linux kernel](https://en.wikipedia.org/wiki/Linux_kernel).
- This will be the operating system you will use in your VMs.

## Why Debian?
- Debian is lightweight, free, and well-supported. It is also the framework Proxmox is built on top of, so its underlying operating system will become familiar.
- [Ubuntu](https://ubuntu.com/) is a popular alternative and has more frequent updates, but we will stick to Debian because it is more lightweight.
