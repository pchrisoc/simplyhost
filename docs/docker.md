# Docker

## What is Docker?
- [Docker](https://www.docker.com/) is a software that packages software into lightweight applications quickly with containers.
- [Docker Compose](https://docs.docker.com/compose/) is how you will manage all of your containers/applications.

## Why Docker?
- With a simple [YAML](https://en.wikipedia.org/wiki/YAML) file, you can launch a fully packaged container (application) within seconds!
- Docker allows for great organization, management and control of your containers. It is also very widely supported.
